# meteor trashy addon public source code repository

A few things to note:

 - This is not where actual development of the addon happens.
 - Code is synchronized from the development repository periodically.
 - Do not expect backport to older Minecraft versions.
 - Do not expect binary releases here. Building the jar is as simple as running `./gradlew jar`.
   You can find build instructions for Bibliotheca Arcana in the readme file in its folder.
 - Consider this addon a rolling release. No tagged release will ever be made, and the version
   number of the mod will not change.
 - Code contribution is not accepted here. Contact echopan (eliminatedphi) on Discord instead.

Below is the original content of README.md.


# private (shh!..), trashy addon for meteor

Current features

 - Data dumping (`ed`, `bd`)
 - Maps management (legacy commands: `md`, `mt`, `ml`, `mih`, but see mapman folder)
 - Advanced entity highlighting (`eh`)
 - Auto Trade
 - Slot highlight (for combinable items and items containing certain map ids)
 - Map Xerox (automated map cloning)
 - NBT Tooltip reimplementation
